# DE Consultancy Website

Enterprise-grade consulting website built with Next.js App Router + Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Optional environment variables

- `NEXT_PUBLIC_SITE_URL` (canonical/sitemap base URL)
- `NEXT_PUBLIC_GA4_ID` (GA4 tracking ID)
- `NEXT_PUBLIC_CALENDLY_URL` (Calendly embed URL)
- `RESEND_API_KEY` (email delivery via Resend)
- `CONTACT_TO_EMAIL` (lead notification destination)
